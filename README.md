# code-generation-engine

Deterministic code generation platform scaffold.

## Apps

- `/apps/api` — generation API contracts and platform table/adapter definitions
- `/apps/worker` — worker role registry
- `/apps/dashboard` — placeholder for full dashboard integration
- `/apps/playground` — lightweight Next.js playground for exercising generation flows

## Playground

```bash
npm install
npm run playground:dev
```

Other commands:

```bash
npm run playground:lint
npm run playground:build
```
